# Data

Everything in this directory except this file is ignored by git.

Document each dataset here: what it is, where it comes from, how to obtain it, and how
it is preprocessed. Acquisition and preprocessing should be done by scripts in
`scripts/`, so that anyone can recreate this directory from scratch.

- **Do not** commit publicly available datasets: commit the script that downloads them.
- **Do not** put data from human participants here without following the group's
  data-management guidelines and your IRB protocol.
